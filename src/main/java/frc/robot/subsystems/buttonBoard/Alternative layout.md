# Alternative layout for the button board in case it isn't available

# Buttons
- ### D pad
    - D pad up: Elevator L4
    - D pad down: Elevator L1
    - D pad left: Elevator L2
    - D pad right: Elevator L3
- ### Triggers
    - Left trigger: Algae intake
    - Right trigger: Algae outtake
- ### Main buttons
    - Start: Manual Controls

# Joysticks
- ### Left joystick
    - Y axis: Manual Elevator
    - X axis: Manual Algae Remover
- ### Right joystick
    - Y axis: Manual Algae arm
    - X axis: Manual Algae Rollers
